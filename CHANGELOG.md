# Что нового

Формат: версия — дата. Раздел версии становится описанием GitHub Release, поэтому пишется для владельца, а не для разработчика.

## v1.1.0 — 2026-10-19

Здоровье, замеры и аналитика набора и сушки. **Нужно обновить Apps Script до API 5** (новое развертывание не нужно, URL и ключи прежние). Пока скрипт старый, новые данные ждут на телефоне, остальное работает. Старые восемь вкладок таблицы не меняются, всё новое — в листах `App_*`.

**Вкладка «Тело»**
* Вес по взвешиваниям: среднее за 7 дней, темп в кг и в % массы в неделю, график. Подозрительные взвешивания помечаются с причиной и не удаляются.
* Сон по дате пробуждения: весь сон за сутки (из него считается среднее) и отдельно основной сон, если сон был в несколько частей. Фазы называются как в «Здоровье»: базовый, глубокий, REM.
* Обхваты и их изменение за 4+ недели. Процент жира с весов показан как оценка.
* Ручные замеры, исправления, «учитывать / не учитывать» для взвешивания, удаление с возвратом.

**Загрузка истории из файлов**
* CSV веса и сна из «Здоровья», CSV Fitdays+. Перед загрузкой — сводка: новые, уже есть, похожие, ошибки по строкам. Загрузку можно отменить целиком.
* Перед сверкой приложение синхронизируется с таблицей, чтобы данные из «Команд» не повторились. Без связи сводка об этом предупреждает.

**«Команды» iPhone**
* Вес, талия и сон приходят из «Здоровья» автоматически: при закрытии Zepp Life и Fitdays+ и раз в день. Отдельный ключ только добавляет данные. Инструкция — docs/SHORTCUTS.md.
* Каждый запрос отмечается в `App_HealthLog` с количеством и причиной отказа, без значений. Если строка не принята, команда может показать уведомление с причиной.

**Режимы набора, сушки и поддержания**
* Режим с датами и целевым темпом (% массы в неделю), лист `App_Phases`. Новый режим завершает текущий накануне.
* Карточка режима: темп веса против цели, средний вес по неделям, талия против веса, силовые в ту же неделю цикла в начале и в конце режима, сон за период. Когда данных мало, так и написано, с тем, чего не хватает.
* Цифры описывают, что происходило, а не почему.

## v1.0.2 — 2026-10-19

Небольшой патч после проверки v1.0.1 на iPhone. Apps Script не меняется (API 3, как в v1.0.1). Если обновляетесь сразу с v1.0.0 — включает и v1.0.1 (ниже), тогда Apps Script нужно обновить до API 3.

**Окна снизу**
* В шапке каждого окна — кнопка «Закрыть» (×). Шапка не прокручивается вместе с содержимым.
* В длинных формах (упражнение программы, подход, комментарий, настройки, самочувствие, итог тренировки, ручной рекорд) основная кнопка закреплена внизу окна и видна над клавиатурой.
* Если в форме есть несохранённые изменения, ×, касание фона и Escape сначала спрашивают «Закрыть без сохранения?».
* Редактор программы: пока есть несохранённые изменения, вверху есть «Сохранить»; «Назад» без сохранения спрашивает, выйти ли; нижние вкладки в редакторе скрыты, чтобы не уйти из него случайно.
* Двойное касание «Сохранить» в окне подхода или комментария больше не записывает лишний подход (второе касание попадало на «Записать»).
* Многострочные поля — шрифт 16 px: iPhone больше не увеличивает страницу при вводе.

**Настройки тренажёра в редакторе программы**
* Настройки → Программа → упражнение: у каждого варианта своё поле настроек (сиденье, рукоятки, ограничители). Это те же настройки, что в строке «Настройки» над подходами, и они так же синхронизируются через `App_Exercises`.
* Заметка тренера — отдельное поле, общее для упражнения и всех вариантов.
* В списке упражнений видно, где настройки заданы.

Тренировки, подходы, рекорды и их логика не менялись.

## v1.0.1 — 2026-10-19

Патч после первой тренировки. **Нужно обновить Apps Script до API 3** (новое развертывание не нужно, URL и ключ прежние) — иначе настройки упражнений ждут на телефоне; всё остальное работает и без обновления.

**Исправление тренировки 18 октября** (карточка на главном экране, применяется только по кнопке «Исправить»)
* «Гиперэкстензия с весом» → «Гиперэкстензия в тренажере», «Кроссовер на заднюю дельту» → «Обратная бабочка двумя руками», «Подъем EZ-грифа перед собой» → «Тяга штанги к подбородку в Смите». Веса, повторения, RIR, даты и номера подходов не меняются; на телефоне сохраняется резервная копия, есть «Отменить».
* Программа, день 2: основные варианты — гиперэкстензия в тренажере и тяга к подбородку в Смите (прежние — альтернативы), к кроссоверу добавлены «Обратная бабочка двумя руками» и «одной рукой». У каждого варианта своя серия.

**Заметки и настройки**
* Настройки варианта упражнения: строка «Настройки: сиденье 5, ручки 3» над подходами, своя для каждого варианта, сохраняется между тренировками и синхронизируется (лист `App_Exercises`).
* Значок заметки у каждого подхода: закрашен, если заметка есть, касание открывает подход.
* «Отметки и комментарий» — комментарий к упражнению именно в этой тренировке.

**Исправления**
* «Заменить» в тренировке, где подходы уже записаны, спрашивает: перенести записанные подходы на выбранный вариант (если записали не то) или оставить их (если дальше другой тренажёр).
* Редактор программы: новый основной вариант больше не забирает ключ серии старого — варианты не смешиваются.
* Быстрое двойное касание «Записать» на последнем подходе упражнения больше не записывает первый подход следующего.
* Если запись на телефоне не удалась, изменение не уходит в таблицу: оно откатывается и на экране. То же при получении данных из таблицы: они придут снова при следующей синхронизации.
* Ручная правка альтернатив в `App_Program` без столбца `keys` больше не может отдать вариант чужой серии.
* На самом узком экране метки подхода (RIR, боль, техника, название другого варианта, заметка) переносятся, а не вылезают за край и не закрывают вес.

**Обновление** с v1.0.0 сохраняет все тренировки, подходы, заметки, рекорды и замеры; база на телефоне получает новое хранилище (версия 3).

## v1.0.0 — 2026-10-17

Первая стабильная версия. Принята на iPhone; работает с Apps Script API 2.

**В зале**
* Следующая тренировка по плану: периодизация из 3 недель, цвет недели, альтернативы как отдельные серии.
* Запись подхода в одно-два касания. Вес и повторения переносятся на следующий подход, правка и отмена любого подхода, защита от двойного нажатия.
* «Прошлый раз» над полями ввода: тот же вариант в ту же неделю цикла, иначе результат другой фазы с пометкой, иначе «Первое выполнение».
* Замена упражнения, отметки «боль», «техника хуже», «новая точка отсчёта», дроп-сеты, заметки.

**Анализ**
* Прогресс, «возможное плато», плато и регресс по одинаковым неделям цикла, по всем рабочим подходам с учётом RIR. Одна неудачная тренировка — не плато.
* Рекорды по числу повторений: находятся в тренировках сами, можно добавить прошлые вручную. Полная история с датами, график, оценка актуальности. Расчётный 1ПМ — только ориентир.
* Вес тела, сон и восстановление.

**Надёжность**
* Офлайн: приложение запускается в авиарежиме, каждое касание сразу сохраняется на телефоне.
* Синхронизация с Google Таблицей (листы `App_*`) без дублей, изменения с других устройств подтягиваются. Запись в таблицу защищена ключом.
* Программа и тренировка 16.10.2026 перенесены из исходной таблицы, исходные листы не изменялись.
* Экран диагностики вместо бесконечной «Загрузки», восстановление файлов приложения без потери данных, работа с включённой блокировкой контента Safari, раскладка без наложений на iPhone от SE до Pro Max.

**Известные ограничения** (исправление — v1.0.1)
* Быстрое двойное касание «Записать» на последнем подходе упражнения может записать и первый подход следующего. Лишний подход виден в списке, его можно отменить или удалить.
* При ошибке записи на телефоне («Не удалось записать») изменение может уйти в таблицу, но не сохраниться на телефоне.

**Обновление с предыдущих сборок** сохраняет все тренировки, подходы, рекорды и замеры на телефоне и не добавляет строк в таблицу. Откат на сборки до «Рекордов» не поддерживается: ошибки исправляются следующими версиями.
