# Домофон → Telegram

Звонят в домофон Дом.ру — в Telegram приходит кадр с камеры и кнопка **🔓 Открыть**. Ответить можно из любого места.

```
🔔 Звонок в домофон
Калитка 2 · 15:02:41
[ 🔓 Открыть ] [ 📷 Обновить ]
```

После нажатия подпись меняется на «✅ Открыто в 15:02:50 (Влад)», так что видно, кто впустил.

Нужен только Python 3.9+, библиотеки ставить не надо.

## Как это работает

- Бот раз в 3 секунды забирает список событий домофона из того же API, что и приложение «Умный дом.ру».
- Новое событие со словом `call` в типе считается звонком. Бот берёт кадр с камеры домофона и рассылает его в разрешённые чаты.
- Кнопка «Открыть» работает 3 минуты. Если нажать её позже, бот попросит отправить `/open`, чтобы дверь случайно не открылась от старого уведомления.
- Чужие чаты ничего не могут сделать: на `/start` бот присылает им только их chat_id.

API неофициальный, описан по открытому проекту [ad/domru](https://github.com/ad/domru). Дом.ру может его поменять.

## Установка

1. **Создай бота.** Напиши [@BotFather](https://t.me/BotFather) команду `/newbot` и получишь токен.
2. **Скопируй конфиг** и впиши токен:
   ```bash
   cp config.example.json config.json
   ```
3. **Войди в Дом.ру** (понадобятся номер телефона и SMS, как в приложении):
   ```bash
   python3 domofon_bot.py login
   ```
   Выбери адрес и дверь, которую будет открывать кнопка. Токены сохранятся в `config.json`, этот файл не попадает в git.
4. **Узнай свой chat_id.** Запусти `python3 domofon_bot.py run` и напиши боту `/start`. Он пришлёт число: впиши его в `allowed_chat_ids`, например `[123456789]`. Можно добавить несколько человек.
5. **Проверь доступ:**
   ```bash
   python3 domofon_bot.py check
   ```
   Команда выводит адрес, двери и последние события и сохраняет кадр в `snapshot.jpg`.
6. **Запусти:** `python3 domofon_bot.py run`

## Первый звонок: проверь, что бот его видит

Название события «звонок» в API Дом.ру я не знаю наверняка. Поэтому бот ищет в типе события слово `call`.

1. Позвони сам себе в домофон.
2. Отправь боту `/events` или выполни `check`. Найди строку со своим звонком.
3. Если в её типе нет `call`, впиши подходящее слово в `call_event_markers`.

Пока настраиваешь, можно включить `"notify_all_events": true`: бот будет присылать в Telegram все события подряд.

Звонок появляется в событиях с задержкой: до `poll_seconds` плюс время, за которое его запишет Дом.ру. Если уведомление приходит уже после того, как курьер ушёл, придётся переходить на SIP, см. «Дальше».

## Команды бота

| Команда | Что делает |
|---|---|
| `/photo` | кадр с камеры сейчас и кнопка «Открыть» |
| `/open` | то же самое: дверь открывается только после нажатия кнопки |
| `/events` | последние 10 событий, нужно для настройки |

## Чтобы работало всегда

Подойдёт любой компьютер, который всегда включён: Raspberry Pi, старый ноутбук, роутер с Entware, VPS.

Для Raspberry Pi есть готовый `domofon.service`:

```bash
sudo cp domofon.service /etc/systemd/system/   # поправь пути и пользователя
sudo systemctl enable --now domofon
journalctl -u domofon -f                         # логи
```

## Настройки `config.json`

| Поле | По умолчанию | |
|---|---|---|
| `telegram_token` | | токен от BotFather |
| `allowed_chat_ids` | `[]` | кому приходят звонки и кто может открывать |
| `poll_seconds` | `3` | как часто проверять события |
| `open_button_ttl` | `180` | сколько секунд работает кнопка «Открыть» |
| `call_event_markers` | `["call"]` | слова в типе события, по которым узнаётся звонок |
| `notify_all_events` | `false` | присылать все события, удобно при настройке |

Поля `access_token`, `refresh_token`, `place_id`, `access_control_id` и `door_name` заполняет команда `login`. Когда токен истекает, бот обновляет его сам.

## Дальше

- **Мгновенные звонки через SIP.** Приложение Дом.ру получает звонок по SIP. Если подключиться к SIP напрямую, уведомление будет приходить сразу, а не через опрос событий.
- **Несколько дверей.** Отдельная кнопка для каждой калитки.
- **Курьерский режим.** Команда `/courier 30`: следующие 30 минут бот открывает дверь сам и присылает кадр того, кто вошёл.

```bash
python3 -m unittest -v test_domofon_bot
```
