# Дорожная карта

## v1.0.0 — первая полноценная версия (кандидат, ждёт приёмки на iPhone)

* Запись тренировок между подходами, периодизация 3 недели, альтернативы как отдельные серии.
* Офлайн: запуск в авиарежиме, всё сохраняется на телефоне; синхронизация с Google Таблицей без дублей.
* Анализ прогресса и плато по одинаковым неделям цикла; «Прошлый раз» в панели ввода.
* Рекорды: по числу повторений, из тренировок автоматически и вручную, полная история, оценка актуальности.
* Устойчивость на iPhone: диагностика запуска, восстановление файлов приложения, работа с блокировщиками контента, раскладка без наложений.

Приёмка — [docs/ACCEPTANCE.md](docs/ACCEPTANCE.md). После подтверждения: финальное ревью, merge в `main`, тег `v1.0.0`.

## После v1.0.0 — следующий этап (не начат)

Записано по просьбе владельца, пока не реализуется.

### Apple Health

* Импорт **сна** (длительность, по возможности фазы) и **веса тела** в «Тело» вместо ручного ввода.
* Ограничение платформы: веб-приложение (PWA) не имеет доступа к HealthKit. Реалистичные пути:
  * **Быстрые команды iOS** (Shortcuts): автоматизация раз в день читает данные Здоровья и отправляет их POST-запросом в Apps Script с тем же ключом (новый лист `App_Health` или запись в `App_Metrics`), а приложение получает их при синхронизации.
  * Ручной экспорт из Здоровья (XML/CSV) и импорт файла в приложение — как запасной вариант.
* Идемпотентность как сейчас: одна запись на дату, детерминированный id, данные из Здоровья помечены источником.

### Fitdays+ (умные весы)

* Импорт **замеров**: вес, % жира, мышечная масса, вода, висцеральный жир.
* Fitdays+ умеет передавать часть показателей в Apple Health, тогда подходит путь через Быстрые команды. Иначе — экспорт CSV из Fitdays+ и импорт в приложение.
* Сначала проверить, какие поля Fitdays+ реально отдаёт, и только их показывать; ничего не досчитывать.

### Аналитика набора и сушки

* Фаза (набор / поддержание / сушка) с датами.
* Темп изменения веса относительно цели, тренд по скользящему среднему, состав тела, если есть замеры.
* Связь с силовыми: рекорды и уровень по рабочим подходам на фоне фазы; на сушке снижение не выдаётся за регресс.
* Осторожные выводы: при малом количестве замеров честное «недостаточно данных».
