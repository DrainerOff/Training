# Приёмка v1.0.0 на iPhone

Сборка указана в Настройках внизу: «Версия 1.0.0, сборка …». Блокировку контента в Safari не выключайте.

## Перед проверкой

- [ ] Приложение обновилось: в настройках новая сборка (если нет — закрыть и открыть с иконки).
- [ ] Apps Script обновлён до API 2 (см. [SETUP.md → «Обновление Apps Script для „Рекордов“»](SETUP.md)): URL `/exec` в браузере отвечает `"api":2`.

## Рекорды

- [ ] Прогресс → «Рекорды»: список упражнений со статусами; у данных 16.10 — «Мало данных» и пояснение «Недостаточно данных для оценки».
- [ ] Карточка «Жим штанги лежа: Штанга - горизонт»: рекорды на 7 и 10 повторений, нет рекорда на 1 повторение; расчётный 1ПМ подписан как ориентир.
- [ ] «+» → добавить прошлый рекорд (например, Hammer 95×5, дата в прошлом году, заметка) → в карточке строка «5 повт. 95 кг» с пометкой «вручную» и годом в дате.
- [ ] Изменить эту запись (повторения ±) и удалить её → «Вернуть» восстанавливает; остальная история не меняется.
- [ ] Во время тренировки записать подход больше прошлого (тот же вариант и число повторений) → в панели ввода «Новый рекорд: …»; в «Рекордах» новый рекорд и прежний результат видны в истории.
- [ ] Hammer и «Гантели — наклон», наклон и горизонт, разные хваты подтягиваний — разные карточки.
- [ ] График: переключатели по числу повторений и «1ПМ (расчёт)»; ничего не налезает.

## Офлайн и синхронизация

- [ ] Авиарежим → открыть приложение с иконки → добавить ручной рекорд → закрыть и открыть → запись на месте.
- [ ] Выключить авиарежим → «Синхронизировать сейчас» → в таблице лист `App_Records` с этой записью, `App_Sets` без дублей.

## Не сломалось

- [ ] Тренировка: «Прошлый раз» над полями, панель ввода не перекрывается при прокрутке, нижней навигации нет; «⋯» → разделы.
- [ ] Настройки: прокрутка вниз и вверх, после клавиатуры нет пустоты под навигацией.
- [ ] Прогресс (переключатель «Прогресс»): сравнение недель как раньше.

Если что-то не так — номер сборки, скриншот и что делали.
