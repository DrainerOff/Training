# Установка: от GitHub до iPhone (≈20 минут)

Шаги 1–2 удобнее делать на компьютере: редактор Apps Script на телефоне неудобен. Шаг 3 — на iPhone.

## Шаг 1. Опубликовать приложение (GitHub Pages, бесплатно)

1. Откройте https://github.com/DrainerOff/Training → **Settings → General**. Внизу, в блоке «Danger Zone»: **Change repository visibility → Change to public** → подтвердите.
2. Откройте вкладку **Actions**. Дождитесь зелёного прогона **«Tests and publish»** для ветки `claude/strength-tracker-pwa`, это около 5 минут. Прогон тестирует приложение и создаёт ветку `gh-pages` с готовым сайтом.
   Если прогона нет: **Actions → Tests and publish → Run workflow → Branch: `claude/strength-tracker-pwa` → Run workflow**.
3. **Settings → Pages → Build and deployment**:
   * **Source:** Deploy from a branch
   * **Branch:** `gh-pages`, папка `/ (root)` → **Save**
4. Через 1–2 минуты вверху страницы Pages появится «Your site is live at **https://draineroff.github.io/Training/**».

Проверка: откройте этот адрес на компьютере. Должна быть главная «Следующая по плану: День 2» и карточка «Перенесено из Google Таблицы».

## Шаг 2. Google Apps Script — синхронизация с таблицей

1. Откройте таблицу **«Тренировки - прогресс и плато (Google Таблица)»** → меню **Расширения → Apps Script**. Откроется редактор с файлом `Code.gs`.
2. Откройте код скрипта: https://github.com/DrainerOff/Training/blob/claude/strength-tracker-pwa/apps-script/Code.gs → кнопка **Copy raw file** (значок копирования над кодом справа).
3. В редакторе Apps Script выделите всё в `Code.gs` (Cmd/Ctrl+A), вставьте скопированное и сохраните (значок дискеты или Cmd/Ctrl+S).
4. В панели над кодом выберите функцию **`setup`** → **Выполнить**.
   * Появится «Требуется авторизация» → **Проверить разрешения** → ваш аккаунт.
   * Google покажет «Приложение не проверено». Это стандартное предупреждение для личных скриптов: скрипт ваш и работает от вашего имени. Нажмите **Дополнительные настройки → Перейти на страницу проекта (небезопасно) → Разрешить**.
   * Внизу, в «Журнале выполнения», появится **ключ доступа** из 64 символов. Его же всегда можно посмотреть в таблице: обновите вкладку таблицы → меню **Тренировки → Показать ключ доступа**.
   * В таблице появятся листы `App_Sets`, `App_Sessions`, `App_Metrics`, `App_Program`. Старые листы не изменяются.
5. Синяя кнопка **Начать развертывание → Новое развертывание**:
   * шестерёнка «Выберите тип» → **Веб-приложение**;
   * описание: «Тренировки API»;
   * **Запуск от имени: Я** (ваш email);
   * **У кого есть доступ: Все** — именно «Все», а не «Все, у кого есть аккаунт Google»;
   * **Начать развертывание** → если спросит, снова «Разрешить».
6. Скопируйте **URL веб-приложения**. Он оканчивается на `/exec`.
7. Проверка: откройте этот URL в браузере. Должна быть строка вида `{"ok":true,"app":"trainer",...}`. Если браузер просит войти в Google, выбран не тот доступ: **Начать развертывание → Управление развертываниями → ✎ → У кого есть доступ: Все → Развернуть**.

Почему доступ «Все» безопасен — в разделе «Безопасность» ниже.

## Шаг 3. iPhone

1. Откройте в **Safari** адрес https://draineroff.github.io/Training/
2. **Поделиться → На экран «Домой»**. Если есть переключатель «Открывать как веб-приложение», оставьте его включённым → **Добавить**.
3. Дальше открывайте приложение **только с иконки «Тренировки»**. У иконки своё хранилище, отдельное от вкладки Safari.
4. На главном экране будет карточка «Перенесено из Google Таблицы» → **Понятно**.
5. Шестерёнка (или значок статуса вверху) → блок **«Google Таблица»**: вставьте URL `/exec` и ключ.
   Перенести их с компьютера на телефон проще всего через Заметки, AirDrop или универсальный буфер обмена. Ключ — это пароль к таблице: не публикуйте его в общих чатах.
6. **Сохранить и проверить связь**. Должно появиться «Подключено к таблице «Тренировки - прогресс и плато…»», а через несколько секунд — «Синхронизировано в ЧЧ:ММ».
7. Проверьте таблицу:
   * `App_Sets` — 23 строки (16.10);
   * `App_Program` — 29 строк;
   * `App_Summary` — 7 строк, читаемая сводка.
8. Рекомендую включить в настройках «Не гасить экран во время тренировки».

## Шаг 4. Первый тест (чек-лист)

В зале или дома, без нагрузки:

- [ ] «Начать тренировку»: открывается День 2, неделя 2 (синий блин), 7 упражнений.
- [ ] Записать 2–3 подхода. Вес переносится на следующий подход; правка подхода касанием; «Отменить».
- [ ] «Заменить» на другое упражнение и вернуть обратно.
- [ ] Закрыть приложение посреди тренировки (смахнуть из переключателя) и открыть: тренировка продолжается, недописанное число на месте.
- [ ] **Авиарежим:** закрыть приложение полностью → включить авиарежим → открыть с иконки → записать подход → статус «Офлайн, N в очереди» → закрыть и открыть снова → данные на месте.
- [ ] Выключить авиарежим → через несколько секунд «Сохранено» → в `App_Sets` ровно столько новых строк, сколько подходов.
- [ ] Завершить тренировку → следующая по плану: День 3.

Если что-то не так, пришлите мне номер сборки (Настройки, внизу: «Версия 1.0.0, сборка …»), скриншот и что вы делали.

## Обновления

* Я отправляю изменения в ветку → CI прогоняет тесты и публикует сайт примерно за 5 минут.
* На iPhone: откройте приложение — новая версия загрузится в фоне, появится «Загружена новая версия приложения → **Перезапустить**». Все данные к этому моменту уже сохранены. Если сообщения нет, закройте приложение и откройте снова (иногда нужно дважды). Номер сборки — в настройках внизу.
* Если меняется `Code.gs` (я предупрежу): вставьте новый код → сохраните → **Начать развертывание → Управление развертываниями → ✎ → Версия: Новая версия → Развернуть**. URL остаётся прежним, на телефоне ничего менять не нужно.

## Безопасность

* **Таблицу защищает ключ.** 64 случайных символа хранятся только в настройках скрипта (Script Properties) и на ваших устройствах. Без ключа API ничего не читает и не пишет, сравнение ключа идёт за постоянное время. Ни ключа, ни адреса API нет в публичном коде и в истории репозитория (проверено сканированием).
* **«Доступ: Все»** значит только, что запрос не требует входа в Google: иначе приложение на телефоне не смогло бы обращаться к API. Без ключа запрос отклоняется.
* Скрипт пишет **только в листы `App_*`**. Текст из приложения никогда не становится формулой. Запросы больше 5 МБ отклоняются.
* Страница приложения может отправлять данные **только в Google Apps Script**: это ограничено политикой безопасности (CSP). Даже если в браузер попадёт посторонний код, ключ никуда больше не уйдёт.
* **Потеряли телефон или ключ попал в чат:** таблица → меню **Тренировки → Сменить ключ доступа**. Старый ключ перестаёт работать сразу, переразвёртывать скрипт не нужно. Новый ключ введите на своих устройствах.
* Редакторы таблицы видят код скрипта и его настройки, в том числе ключ. Права редактора давайте только тем, кому и так доверяете таблицу.
* Все сайты GitHub Pages одного аккаунта (`draineroff.github.io/…`) работают на общем домене. Не публикуйте там чужой код.

## Если что-то не работает

| Что видно | Причина | Что сделать |
|---|---|---|
| «Веб-приложение не ответило…» при работающем интернете | в развертывании доступ не «Все», или адрес не `/exec` | шаг 2.7: доступ «Все»; URL из «Управление развертываниями» |
| «Это адрес самой таблицы / редактора скрипта / /dev» | скопирован не тот адрес | нужен «URL веб-приложения», оканчивается на `/exec` |
| «Ключ доступа не подходит» | ключ скопирован не целиком или был сменён | «Тренировки → Показать ключ доступа», скопировать заново |
| «Таблица не приняла записей: N» | устаревший `Code.gs` | обновить `Code.gs` и сделать новую версию развертывания; записи ждут на телефоне |
| «Офлайн, N в очереди», хотя интернет есть | Google временно недоступен | ничего: отправится само, данные на телефоне |
| В приложении с иконки нет настроек синхронизации, хотя в Safari вводили | у иконки своё хранилище | ввести URL и ключ в приложении, открытом с иконки |
| Старая версия после обновления | новая версия ещё в фоне | закрыть и открыть приложение; сверить номер сборки |
| Экран «Приложение не запустилось» с названием этапа | приложение не дождалось ответа на этом этапе (чаще всего от базы на устройстве) | «Повторить». Если экран повторяется: «Скопировать отчёт» и прислать мне. Данные на устройстве этот экран не трогает |
| «Обновляю файлы приложения…» | файлы приложения в памяти телефона испорчены, приложение скачивает их заново | ничего: страница перезапустится сама; нужен интернет |
| Красная плашка «Временный режим» | вы выбрали «Продолжить без сохранения», потому что база на устройстве не открылась | «Открыть с сохранением», когда будет время; во временном режиме записи живут до закрытия вкладки |
