# Питание из ChatGPT: как итог дня попадает в приложение

В приложении питание хранится только итогами дня: калории, белки, жиры, углеводы. Продуктов, приёмов пищи и фото нет. Есть три пути записи, и для всех действуют одни и те же правила:

1. **Вручную в приложении** («Тело → Питание → Записать день»). Работает без сети, правится и удаляется, уходит в таблицу при синхронизации.
2. **ChatGPT пишет строку в лист `App_NutritionInbox`.** Apps Script проверяет её и переносит день в `App_Nutrition`.
3. **Вставка блока из ChatGPT** («Питание → Вставить из ChatGPT»). Это запасной путь, если ChatGPT не может писать в таблицу. Блок проходит те же проверки, что и строка в листе.

Приложение и Claude не читают вашу переписку с ChatGPT. В приложение попадает только то, что ChatGPT записал в `App_NutritionInbox`, или то, что вы вставили сами.

## Почему ChatGPT пишет во «входящие», а не прямо в `App_Nutrition`

| | A. ChatGPT пишет в `App_Nutrition` | B. ChatGPT пишет в `App_NutritionInbox`, переносит Apps Script (сделано так) |
|---|---|---|
| Повторный «Закрыть день» | Добавит вторую строку за ту же дату. Дубль увидит телефон, средние посчитаются дважды. | Новая строка во «входящих» с результатом «без изменений». В `App_Nutrition` по-прежнему одна строка на дату. |
| Синхронизация с телефоном | Не сработает надёжно. Правки через Sheets API не запускают `onEdit`, поэтому у строки нет `updated_at` и `_srv`, и телефон её не увидит. Или увидит, но перезапишет своей версией. | Apps Script ставит `id`, `updated_at` и `_srv` сам, под той же блокировкой, что и синхронизация. Телефон получает день как обычную запись. |
| Проверка значений | Нет. Опечатка «32000 ккал» или «22.13.2026» попадёт в данные. | Дата, числа, диапазоны и статус проверяются. Неверная строка получает «отклонён: …» с причиной, данные не меняются. |
| Черновик после итога | Затрёт итог. | Пропускается: «пропущен: черновик не заменяет итог». |
| Ваши ручные правки | Затрутся молча. | Заменённые ручные значения сохраняются (`prev_json`). В приложении есть «Вернуть мои». |
| Что нужно от ChatGPT | Знать служебные столбцы и не трогать их. | Только добавлять строку из 8 понятных столбцов в конец одного листа. |

**Компромисс варианта B.** День появляется в `App_Nutrition`, когда Apps Script обработает «входящие». Это происходит при каждой синхронизации с телефона (приложение синхронизируется при открытии и после записей) и по меню **Тренировки → Принять питание из ChatGPT** (меню есть только в браузере на компьютере). Пока телефон не синхронизировался, строка просто ждёт во «входящих».

**Что вариант B не решает.** Если у ChatGPT есть право записи в таблицу, оно действует на всю таблицу, а не на один лист. Ограничить его одним листом можно только инструкцией. Поэтому:
* инструкция ниже прямо запрещает трогать другие листы и строки;
* перед подключением сделайте резервную копию (**Тренировки → Резервная копия таблицы**), а при сомнениях смотрите **Файл → История версий**;
* если давать ChatGPT доступ к таблице не хочется, пользуйтесь только вставкой блока (путь 3). Она надёжна так же, просто нужен один лишний шаг.

## Листы и столбцы

### `App_NutritionInbox` — сюда пишет ChatGPT (только добавляет строки)

| Столбец | Что писать | Пример |
|---|---|---|
| `date` | учётный день, ГГГГ-ММ-ДД (или ДД.ММ.ГГГГ) | `2026-10-22` |
| `kcal` | калории: число, `~число` или диапазон | `3250`, `~3200`, `3100-3300` |
| `protein_g` | белки, г | `160` |
| `fat_g` | жиры, г | `90` |
| `carbs_g` | углеводы, г | `420` |
| `status` | `итог` или `черновик` | `итог` |
| `approx` | `да` или `нет` | `нет` |
| `comment` | коротко, до 300 знаков | `ужин в гостях, оценка` |
| `written_at` | когда записано (для вас; на обработку не влияет) | `2026-10-23 02:10` |
| `result` | **заполняет Apps Script**: создан / обновлён / без изменений / пропущен / отклонён: причина | |
| `processed_at` | **заполняет Apps Script**: когда обработано | |

Пустое значение остаётся пустым: ничего не придумывается и не складывается. Строка без статуса принимается как черновик, а в `result` дописывается «(статус не указан — черновик)». Обработанные строки не удаляются и больше не меняются, поэтому лист служит журналом. Apps Script записывает в строку только `result` и `processed_at`.

### `App_Nutrition` — дни (пишут приложение и Apps Script)

`date`, `kcal`, `protein_g`, `fat_g`, `carbs_g` — значения дня. `ranges` — диапазоны, если они были (JSON, например `{"kcal":[3100,3300]}`; в средних берётся середина с пометкой «≈»). `approx`, `status` (`final` или `draft`), `source` (`manual`, `chatgpt`, `import`), `comment`. Служебные столбцы: `ext_rev` (отпечаток записи ChatGPT), `prev_json` (заменённые ручные значения), `batch` (загрузка старых дней), `id`, `updated_at`, `deleted`, `_srv`.

Править дни лучше в приложении. Правка ячейки в браузере тоже дойдёт до телефона, но служебные столбцы не трогайте.

### `App_NutritionGoals` — цели по режимам

`phase_id` — режим из `App_Phases`, `from` — с какой даты действуют. Цели в столбцах `kcal_min`/`kcal_max`, `protein_min_g`/`protein_max_g`, `fat_min_g`/`fat_max_g`, `carbs_min_g`/`carbs_max_g`. `carbs_mode`: `rest` — углеводы считаются остатком калорий после белков (4 ккал/г) и жиров (9 ккал/г), `explicit` — задаются сами. Цели задаются в приложении. Смена целей с новой даты добавляет строку, поэтому прошлые дни считаются по прежним целям.

## Ключ дня и правила

Ключ дня — дата: `id = n:ГГГГ-ММ-ДД`. В `App_Nutrition` за дату всегда одна строка.

1. **Повтор ничего не меняет.** Для каждой записи считается отпечаток значений (`ext_rev`): дата, четыре значения, статус, «приблизительно», комментарий. Если тот же «Закрыть день» пришёл ещё раз с теми же числами, будет «без изменений», даже если день удалён в приложении.
2. **Черновик не заменяет итог.** Промежуточный итог за день, у которого уже есть итог, пропускается.
3. **Иначе выигрывает более позднее действие.** Пересчитанный итог за ту же дату обновляет день. Если он заменил ваши ручные значения, они сохраняются, и в «Питании» появляется «Вернуть мои» / «Оставить ChatGPT».
4. **Удалённый день** возвращается только новой записью, то есть с другими числами.
5. **Ручная правка без сети.** Если вы поправили день на телефоне без сети, а ChatGPT тем временем записал итог, Apps Script при синхронизации оставит запись ChatGPT как более позднюю, а вашу правку сохранит в `prev_json`. «Вернуть мои» вернёт её одним нажатием.

### Пример: 22.10 закрыт дважды, потом пересчитан

| Что произошло | Строка во «входящих» | `result` | `App_Nutrition`, строка `n:2026-10-22` |
|---|---|---|---|
| 23.10 в 02:10 «Закрыть день» | 2026-10-22, 3250 / 160 / 90 / 420, итог | создан | 3250 / 160 / 90 / 420, итог, ChatGPT |
| Через минуту «Закрыть день» ещё раз | то же | без изменений | без изменений |
| Днём «пересчитай 22.10, забыл перекус» | 2026-10-22, 3400 / 165 / 95 / 430, итог | обновлён | 3400 / 165 / 95 / 430 — та же строка |
| Вечером случайный промежуточный итог за 22.10 | 2026-10-22, 1800, черновик | пропущен: черновик не заменяет итог | без изменений |

Эти случаи проверяют тесты `tests/server/nutrition-sync.test.js` и `tests/e2e/nutrition.spec.js`, на синтетических числах.

## Учётный день

Учётный день — тот, что начался по команде «Новый день», даже если «Закрыть день» прозвучит в 5 утра. Дату ставит ChatGPT. В приложении новая ручная запись по умолчанию идёт во вчерашний день до 07:00 (настройка «Питание → Учётный день»). Дату в записи всегда можно поменять. Полночь ничего не переносит.

## Как проверить, что день дошёл

* **В приложении:** «Тело → Питание → Дни». У дня указаны источник «ChatGPT» и статус «итог подтверждён» или «черновик». Черновики не входят в средние.
* **В таблице:** в `App_NutritionInbox`, в столбце `result` у вашей строки. Если там пусто, строку ещё не обработали: откройте приложение или нажмите **Тренировки → Принять питание из ChatGPT**.
* **Ошибка:** «отклонён: …» с причиной. Например, «калории: вне диапазона 0–15000». Исправленную запись нужно добавить новой строкой.

## Без секретов

ChatGPT не нужен ни адрес Apps Script, ни ключ доступа, ни ключ для «Команд». Не отправляйте их в чат. «Входящие» — обычный лист вашей таблицы, а вставка блока работает вовсе без сети.

## Инструкция для ChatGPT (один раз)

Её же можно скопировать в приложении: «Питание → Как подключить ChatGPT → Скопировать инструкцию». Отправьте её один раз в чат, где вы ведёте питание.

```
Веди мой дневник КБЖУ только итогами дня (ккал, белки, жиры, углеводы), без списка продуктов.
Учётный день начинается по моей команде «Новый день» и заканчивается командой «Закрыть день», даже если это после полуночи. Дата дня — дата на момент «Новый день».
По «Закрыть день» подведи итог и:
1) если можешь добавлять строки в мою Google Таблицу «Тренировки - прогресс и плато» — добавь ОДНУ новую строку в конец листа App_NutritionInbox (другие листы и строки не трогай, ничего не удаляй и не исправляй): date = ГГГГ-ММ-ДД, kcal, protein_g, fat_g, carbs_g (числа; если точно не знаешь — диапазон вида 2800-3000), status = итог, approx = да или нет, comment = коротко, written_at = текущие дата и время;
2) в любом случае выведи блок для вставки в приложение:
Дата: ГГГГ-ММ-ДД
Ккал: … · Белки: … · Жиры: … · Углеводы: …
Статус: итог · Приблизительно: да/нет · Комментарий: …
Промежуточный итог до «Закрыть день» — то же, но статус черновик. Если пересчитываешь закрытый день — тот же формат и та же дата, новые числа. Не складывай разные дни, не придумывай значения: чего не знаешь — оставь пустым.
```

## Старые дни

«Питание → Загрузить старые дни» принимает таблицу CSV с заголовком (дата, ккал, белки, жиры, углеводы, статус; разделитель `;`, `,` или табуляция) или дни блоками, как из ChatGPT. Перед записью показывается предпросмотр: новые дни, совпадающие, отличающиеся (заменяются только отмеченные) и ошибки с номером строки. Одна дата дважды — ошибка, дни не складываются. Загрузку можно отменить кнопкой «Отменить» сразу после записи.
